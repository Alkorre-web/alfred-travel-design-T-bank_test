# Система отслеживания рейсов "Альфред"

Решение тестового задания для стажировки в Т-Банке (TravelTech кейс)

## О проекте
Система мониторинга статусов рейсов и автоматического предложения альтернатив при задержках или отменах. Сервис интегрируется в платформу планирования путешествий, обеспечивая бесшовный опыт для пользователя даже в форс-мажорных ситуациях.

## Ключевые особенности решения
- Автоматический подбор альтернатив с учетом визовых требований, багажа и тайм-зон
- Поддержка оффлайн-режима с очередью уведомлений
- Строгое соблюдение требований безопасности: автоматическое удаление паспортных данных через 24 часа после завершения поездки
- Микросервисная архитектура для независимого масштабирования компонентов
