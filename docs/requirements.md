# Требования к системе "Альфред"

## Функциональные требования

FR1: Система должна получать информацию о статусах рейсов из внешних API авиакомпаний
FR2: Система должна отслеживать изменения статусов (задержка, отмена, изменение времени)
FR3: Система должна уведомлять пользователей об изменениях статуса их рейсов
FR4: Система должна автоматически предлагать альтернативные рейсы при задержке или отмене
FR5: Система должна учитывать наличие багажа при подборе альтернатив
FR6: Система должна проверять визовые требования для альтернативных маршрутов
FR7: Система должна учитывать тайм-зоны при планировании пересадок
FR8: Система должна обновлять общий план путешествия после согласования альтернативы
FR9: Система должна поддерживать работу в оффлайн-режиме (очередь уведомлений на устройстве)

## Нефункциональные требования

NFR1: Паспортные данные должны удаляться не позднее чем через 24 часа после завершения поездки
NFR2: Система должна обрабатывать задержки данных от внешних API (до 30 минут)
NFR3: Уведомления должны доставляться в течение 5 минут после обнаружения изменения статуса
NFR4: Система должна быть отказоустойчивой при недоступности внешних API
NFR5: Персональные данные должны храниться в зашифрованном виде
NFR6: Система должна поддерживать многопользовательский режим (семейные или групповые поездки)
